# Tohi-GT7 1.0.1 — 蒙扎／纽北补帧与简体中文显示修复

本版针对蒙扎、纽北座舱及车外视角中发现的补帧回退原因，修正相机验证与场景效果合成，并包含行驶中闪退防护和简体中文缺字修复。

**验证范围：6 项自动化回归测试通过；最新改动尚未完成蒙扎／纽北各视角的最终游戏内验收。此前中间版本已记录有效生成帧，但仍出现间歇停用，因此本版不承诺所有赛道、视角均可全程连续补帧。**

修正帧生成相机识别仅覆盖少数着色器的问题：旧版在 BB 能开启帧生成，换到蒙扎等使用其他着色器的赛道时，会因相机未被识别而回退。

## 更新内容

- 相机识别新增对着色器实际位置计算的校验，支持等价的模型矩阵与相机矩阵组合方式，不再只依赖几个测试时记录的着色器编号，也不按赛道名称单独放行。
- 相机参数由实际使用的当前矩阵及同帧 TAA 抖动共同验证，不再要求其他着色器的附加常量区也遵循 BB 样本的布局。本机采集的 64 份当前相机样本均通过独立复算，其中 40 份会被旧的附加常量区检查误拒。
- 修正连续多次已验证后处理被误判为不支持的情况，不再要求模糊只能是第一层、叠加只能是第二层；每笔绘制仍需通过纹理、资源反馈、输出及混合检查。
- 支持诊断中反复中断场景合成的一组额外几何效果，处理已验证的透明叠加与加法混合，保留顶点阶段资源检查。无法证明安全的反馈覆盖链继续回退；自动化合成校验不等同于游戏内画质与连续性验收。
- 防止行驶中像素着色器引用了运行时未提供的输入时导致整个程序退出。此类错误输入变体会被跳过，正常输入变体仍照常绘制；这不代表已恢复该笔缺失输入绘制的内容。
- 保留同帧深度、运动矢量、相机抖动和无 HUD 画面的关联检查，并校验深度映射，避免错误相机数据进入帧生成。UI 防闪烁和车轮拖影修正保持启用。
- 增加 `Start-GT7-Desktop.cmd`，与 `launcher.exe` 使用同一正式版启动流程和保存的 DLSS 复选框状态。不会转到旧 SR 测试程序，也不会创建新的测试存档目录。
- 窗口标题明确标注游戏原始帧率；这个数字不包含 FSR 生成帧，不能用是否翻倍判断帧生成是否工作。
- 普通日志保留低频帧生成状态、生成计数及回退原因，便于诊断持续 standby 或运行库加载失败。无需打开大量 API 调试日志。
- 修复字体缺少中文字形时直接替换成“？”的问题：支持 TTC 字体集合，并随包附带开放许可的 Noto Sans CJK SC Regular 字体，为缺失字符提供备用字形；非中文 Windows 也无需额外安装中文字体。游戏原有字体能够显示的字符继续使用原字体，字符尺寸计算和实际绘制使用同一字形来源。这是文字显示修复，不修改游戏翻译。
- 保留一个 DLSS 复选框控制固定 1080p → 1440p DLSS 超分、Vulkan FSR 3.1.4 2× 帧生成与车轮拖影修正的设置。

## 使用与升级

完整解压后运行 `launcher.exe` 或 `Start-GT7-Desktop.cmd`，保持 DLSS 勾选。在原安装目录升级时，先退出游戏，再替换程序文件，并保留 `_DownloadData`、`_SaveData`、`_Trophies` 及配置文件。

着色器缓存格式已更新，首次进入场景会重新编译着色器，期间可能暂时卡顿。无需删除存档。

完整发行包包含 `fonts/NotoSansCJKsc-Regular.otf`，用于开箱显示简体中文及常用中日韩字符。字体为未经修改的官方 2.004 静态版本；OFL 1.1 许可证、来源版本与校验值位于 `licenses/fonts/noto-cjk`。升级时请连同 `fonts` 和 `licenses` 文件夹一起复制。程序仍可读取本机已经安装的字体作为其他备用来源，发行包不包含任何 Windows 专有字体。随包字体的常用字形、尺寸与绘制一致性已加入自动化测试；游戏内实际布局仍待验证。

需要游戏显示简体中文时，在启动器的游戏配置中将“主机语言”设为“简体中文”。此版本修复游戏已有中文内容缺字或显示为问号的问题，不替换游戏文件，也不重置存档。

旧开发目录中的 `Start-GT7-DLSS-Playtest.cmd` 曾固定指向仅超分的历史测试程序，不能用于验证正式版帧生成。原始 `kyty_emulator.exe` 需要完整参数和环境设置；日常游玩请使用正式启动器。

## 状态说明

帧生成状态来自运行中的实际生成调用，而非仅检查开关。菜单或不满足深度、运动矢量、相机及无 HUD 画面检查的场景会保留原帧并显示等待状态。生成调用计数与 SDK 呈现计数不等于显示器实际显示帧率；本版不会把原始 FPS 直接乘二。

本次扩展的是已验证的相机计算类型，不代表所有赛道、天气和视角均已实测。复杂分支或无法证明的着色器仍会保留原帧；如果比赛中持续等待，请提供启动器的日志文件夹，其中包含实际生成计数和回退原因。
