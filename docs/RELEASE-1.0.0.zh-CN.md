# Tohi-GT7 1.0.0 正式版

本项目由 KytyPS5-GT7 更名为 **Tohi-GT7**。此版面向 Windows x64 桌面游玩，保留上游项目署名与许可证。

## 本次更新

- 启动器采用 GT7 蓝红背景、深色面板与红色按钮，整理游戏列表和启动操作。
- **DLSS 默认勾选**，一个复选框控制已验证的固定组合：内部 1920×1080 → 输出 2560×1440、DLSS 超分辨率（Quality 提示、Preset K）及 Vulkan FSR 3.1.4 2× 帧生成。开关状态会保存，没有单独的 DLSS 档位或帧生成调节项。
- 固定输入比例为 75%，属于自定义 1080p → 1440p 配置，并非 DLSS 标准质量档的推荐输入分辨率。
- 改进无 HUD 画面提取与 UI 合成，修复此前仪表、文字、地图的明显闪烁。
- 对前后帧运动不连续区域加入局部修正，减轻外部视角下车轮及车身边缘的拖影。
- 移除启动器中的 VR 启动入口，旧 VR 配置不会让桌面启动进入 VR。
- 保持已有配置与存档路径兼容；开发测试辅助脚本也会沿用最近一次正常退出的进度。
- 更新仓库与检查更新链接至 `masterzhang233/Tohi-GT7`。

## 使用

1. 将 Windows x64 压缩包完整解压到可写目录，运行 `launcher.exe`。
2. 添加你自己的兼容 GT7 游戏目录，选择游戏并启动。
3. 默认保持 **DLSS** 勾选，即使用上述固定画面组合；取消勾选会关闭这一整套增强。
4. 从旧版升级时，保留原有 `_SaveData`、`_DownloadData`、`_Trophies` 文件夹。不要把游戏存档加入发布包。

包内包含 DLSS 后端、NVIDIA DLSS runtime（文件版本 **310.9.16.0**）和 FidelityFX Vulkan runtime 及相应许可证，不包含游戏、固件、系统模块或个人存档。DLSS 组合需要兼容的 NVIDIA RTX 显卡；已在 **RTX 3080** 上测试。

## 验证与使用范围

此前现场测试中，用户反馈 UI 闪烁消失、车轮拖影明显减轻且未见新异常；生成计数与配对捕获确认插帧及局部修正执行，独立 GPU 修正测试通过 23 项检查。这些数据不等于显示端 FPS 测量，2× 表示生成比例，不保证每个场景实际帧率翻倍。菜单或尚未识别的相机场景可能进入 standby，局部运动边缘仍可能存在瑕疵。

本次发布的启动器、配置开关、可移植依赖与图形启动检查另行验证。原有 Git 历史保留，旧预览版 Release 在新版验证后下架。
