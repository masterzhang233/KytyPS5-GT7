# GT7 SteamVR 与内部渲染 Preview 2.2

发布日期：2026-11-03。此版本修复部分 **PPSA01317 / 01.710.000** 用户在启动前遇到的
`unsupported eboot.bin` / `executable-image SHA-256` 不匹配问题。

## 本次修复

- 新增对另一份经过逐段比对的 GT7 1.71 可执行映像的支持，同时保留原样本支持。
- 两份样本的 ELF 入口及五个加载段布局一致；加载内容有 51 字节差异，分布在 13 处。
  这些差异不涉及现有桌面／VR 渲染补丁的位置、原始指令及引用的缩放常量。
- 完整映像 SHA-256 的计算规则保持不变。新增映像通过精确指纹匹配，不忽略差异区间，
  也不按版本号或局部补丁字节直接放行其他文件。
- 保留补丁文件 SHA-256、原始指令、标题版本和主模块检查；补丁仍只作用于加载后的内存。
- 日志会区分“已审计的另一映像”和“同一映像的另一种封装”，方便进一步排查。
- 补充真实样本预检和异常输入回归脚本；测试样本不随源码或发行包分发。

## 支持范围

本版仍面向 Windows，以及已解包的 **PPSA01317 / 01.710.000** 游戏。
支持的规范化可执行映像 SHA-256 为：

```text
f2fab719a2f5caab44ed389a87953cefca78905a0b9b081d023ad33bccbe3aaf
b2303c54658ee8c007a7fb0861989397748ac8a04295bdc2049c67673953c71f
```

新增样本的整文件 SHA-256 为
`e3cdeac5e3ce6794e89876a433b0f4579be77e308bf64000e9c388875a2efab3`。
即使界面显示同样的游戏版本，其他映像仍需单独验证。

## 升级步骤

1. 下载此发布页的 Windows x64 完整 ZIP，关闭正在运行的启动器与模拟器。
2. 备份原模拟器目录，将压缩包顶层文件夹内的程序和配套文件覆盖到原目录，
   保留已有存档及个人设置；也可以解压到新目录独立使用。
3. 运行 `launcher.exe`，继续选择原来的 GT7 游戏目录。**无需替换或修改游戏的 `eboot.bin`。**

独立解压使用时，旧目录中的存档和缓存不会自动迁移。如果仍提示不兼容，可使用启动器的
“导出诊断包”，附上错误中的映像哈希及复现步骤。桌面／VR 选项用法见
[GT7 VR 与渲染设置](../GT7-VR.md)。

## 验证结果与限制

- 专项 CLI 回归 **29/29 通过**：两份真实样本各八个预设通过，另外十三项未知映像、
  补丁损坏和参数冲突测试按预期拒绝。
- C++ 映像校验测试及两份真实样本的全部预设通过；原始 eboot 的前后哈希一致。
- 两份样本共十四项渲染分支／常量检查通过。Windows 构建、包内 CRC 与 SHA-256 校验通过。
- 修复验证阶段的扩展 CTest 为 **56/62 通过**，按仓库说明排除了 `kernel_file_system`。
  `save_data_memory` 确认受测试程序路径中的空格影响，同一二进制在无空格路径下通过。
  其余五项失败涉及 DCC 图层和零坐标剔除检查：`shader_recompiler_compute`、
  `graphics_pipeline_rasterization`、`texture_cache_image_overlap`、
  `texture_cache_htile_clear`、`buffer_cache_ranges`。相关图形代码未修改；
  没有进行图形测试的修复前后 A/B，因此不将完整测试套件标记为通过。

本次没有实际启动该样本进入游戏或进行头显测试。已验证的是启动前兼容检查和渲染补丁
输入兼容性，不代表完整游戏、SteamVR 画面、帧率或稳定性已经通过实机验证。

这是实验性预发布版。发行包不包含游戏、存档、缓存、运行日志、PDB 或转储文件。
本分支继续基于 [usa-ratt/KytyPS5-GT7](https://github.com/usa-ratt/KytyPS5-GT7)
的 `KytyPS5-2026-10-26-55a02de`，保留上游贡献者署名。
