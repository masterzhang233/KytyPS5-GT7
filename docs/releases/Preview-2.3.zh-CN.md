# GT7 SteamVR 与内部渲染 Preview 2.3

发布日期：2026-11-03。本版将模拟器基线从上游 10 月 26 日版升级到
[10 月 28 日第二版 `KytyPS5-2026-10-28-f908636`](https://github.com/usa-ratt/KytyPS5-GT7/releases/tag/KytyPS5-2026-10-28-f908636)
（提交 `f9086362bf80358ec8420d531b4db7deeadc023b`），合入期间的 29 个提交。
保留 Preview 2.2 的 eboot 兼容修复、中文启动器、SteamVR、内部渲染分辨率及诊断功能。

## 上游升级内容

- **方向盘支持：**加入 mixo03 的方向盘、踏板和换挡器映射及力反馈，向游戏模拟
  Fanatec Gran Turismo DD Pro。功能默认关闭，需要在启动器的方向盘设置中配置。
  至少映射转向、油门和刹车，并进行力反馈测试；撞墙时反馈较弱或缺失仍是上游已知限制。
- **幽灵车透明显示：**按游戏的棋盘格 AA 掩码处理相关绘制，修复幽灵车显示为实心的问题。
  首次出现时相关着色器需要后台编译，可能短暂仍显示为实心。
- **GT Sophy 自定义比赛：**合入像素着色器输入布局修复，处理
  `SPI_PS_INPUT_ADDR` 与 `SPI_PS_INPUT_ENA` 不一致时的输入布局，修复上游报告的比赛崩溃。
- **GPU 调度与着色器：**合入按游戏同步点安排 GPU 工作、提前准备计算任务，
  以及极小浮点数处理、像素着色器 LDS 使用和纹理布局转换相关优化。
  跳过重复状态设置、精简 barrier 和 red-zone superblock 仍是默认关闭的可选实验功能。
- **显存回收：**合入 SakuraLainMaid 的异步缓冲区回收及先提交 GPU 工作再清理的修复，
  减少回收路径中的等待。保留可选设置 `KYTY_VMA_BLOCK_MB=64`（较小显存分配块）和
  `KYTY_HOLD_COMPILING=1`（大量管线正在编译时，保留上一帧，最多约 5 秒）；本版不默认启用。
- **构建与输入兼容：**Windows 构建采用上游 `race-r171.profdata` PGO 优化配置；
  已有构建目录重新配置时不再反复获取和
  修补 ZArchive；无法识别的控制器映射条目会被跳过，避免因此在启动时退出。

上述内容来自上游更新。上游的帧率、显存占用与耗时测量不代表此分支的桌面或 VR 实测结果，
本版不承诺特定性能提升。

继续精确匹配以下两份已审计的规范化可执行映像 SHA-256：

```text
f2fab719a2f5caab44ed389a87953cefca78905a0b9b081d023ad33bccbe3aaf
b2303c54658ee8c007a7fb0861989397748ac8a04295bdc2049c67673953c71f
```

保留整映像指纹、补丁文件 SHA-256、原始指令及标题版本检查，不按游戏版本号直接放行其他
eboot。补丁只作用于加载后的内存，不改写游戏文件。桌面内部高度与 SteamVR 眼睛分辨率预设、
中文优先界面和逐次启动诊断包继续保留。相关用法见 [GT7 VR 与渲染设置](../GT7-VR.md)。

补齐新增方向盘界面的 106 条中文文案，并修正方向盘对话框的翻译上下文。增加方向盘开关
与桌面／VR 预设共存、设置持久化、旧配置默认值及设备数量翻译的回归检查。

## 升级步骤与着色器缓存

1. 从本发布页**手动下载 Windows x64 完整 ZIP**。这是预发布版，启动器的 GitHub
   latest-release 检查不会选择预发布，可能不会提示本次更新。
2. 关闭启动器和模拟器，备份旧程序目录、存档及个人设置。将 ZIP 顶层文件夹内的程序和
   配套文件一起覆盖到原目录；也可以解压到新目录独立使用。不要只替换单个 EXE。
3. 运行 `launcher.exe`，选择原来的 GT7 游戏目录。**无需替换或修改游戏的 `eboot.bin`。**

从 Preview 2.2 或原 10 月 26 日基线升级时，会跨过 10 月 27 日的着色器编译器变更，
因此**着色器将重新编译一次**。首次进入菜单或赛道时可能短暂缺少场景、车辆细节或出现卡顿，
请等待编译完成；不要据此将旧缓存强行覆盖到新版。上游最新发布说明中的“无需重新编译”
针对相邻版本，不能直接用于这次跨版本升级。

独立解压到新目录不会自动迁移旧目录中的存档和缓存；备份后按原使用方式保留存档与设置。
出现问题时，可通过启动器“导出诊断包”，提供版本、复现步骤和错误信息。

## 验证结果与限制

- Windows x64 / Clang 20.1.8 / Qt 6.10.3 构建通过，采用上游 PGO 配置。
- 两份真实 eboot 的 CLI 预检 **33/33 通过**：20 项桌面、VR 和方向盘参数组合通过，
  13 项未知映像、补丁损坏及参数冲突按预期拒绝；原始游戏文件哈希保持不变。
- 六项兼容检查、OpenVR 路径及启动器专项 CTest 全部通过；VTE、VR 专用队列、
  OpenVR 桥接、眼睛图像四组回归通过，包含预期拒绝的负向用例。
- 显存回收用例适配上游异步完成语义，默认异步及同步回退模式均通过；新增回收期间
  再次写入的保留与发布检查。PM4 同步用例在默认屏障及 renderer 回退模式均通过。
  同时修正测试的命令录制初始化和 Windows 测试程序栈容量；未为通过测试放宽生产检查。
- 扩展 CTest **56/62 通过**，按仓库说明排除 `kernel_file_system`。
  六项失败的断言信息与 Preview 2.2 的验证日志一致：`save_data_memory` 受程序路径空格
  影响，同一新版二进制复制到无空格路径后通过；`shader_recompiler_compute`、
  `texture_cache_htile_clear`、`buffer_cache_ranges` 停在 DCC 图层检查；
  `graphics_pipeline_rasterization`、`texture_cache_image_overlap` 停在零坐标剔除检查。
  这不等于完整套件通过，也不能据此排除这些检查之后尚未覆盖的问题。

用户已反馈 Preview 2.2 的 eboot 修复可以运行；这不等于本次上游升级已完成实机验证。
本次尚未进行实际游戏、SteamVR 头显或方向盘测试，不能据启动前预检推断完整游戏体验、
力反馈、画面质量、帧率或稳定性均已验证。

这是实验性预发布版。发行包不包含游戏可执行文件、游戏资源、存档、缓存、运行日志、PDB
或转储文件。
