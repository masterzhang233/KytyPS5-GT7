# Tohi-GT7 1.0.2 — 上游兼容性与字体排版修复

基于 Tohi-GT7 1.0.1，选择性移植 KytyPS5 2026-11-06 版本中的四组修复。沿用 GT7 专用分支的渲染、方向盘和存档目录实现。

## 更新内容

- **定时器事件**：补齐 `sceKernelDeleteTimerEvent`，游戏删除周期定时器后会真正移除该事件；无效队列或不存在的定时器返回相应错误。当前 GT7 1.71 模块存在该接口的未解析导入，但尚未测得本版带来的帧率变化。[上游 a7e14aa7](https://github.com/KytyPS5/KytyPS5/commit/a7e14aa716844006e583516f457f452c58815a80)
- **深度处理**：启用 HTile 且关闭深度压缩的绘制，即使关闭深度测试，也会绑定深度附件，使待处理的快速清除能够生效；未压缩深度纹理可保留闲置的元数据对齐标志，其他非法控制位与压缩地址检查继续保留。[上游 b64e430b](https://github.com/KytyPS5/KytyPS5/commit/b64e430b93c209fd431c6d0dc4ad783af6c8e981)、[c1d1003d](https://github.com/KytyPS5/KytyPS5/commit/c1d1003d8e7fb2e8e75a18c72aac736ecc5ebe09)
- **存档挂载**：重复挂载返回 BUSY 等错误时保留调用方已有的挂载结果，避免清掉仍可使用的挂载点。[上游 dfec14aa](https://github.com/KytyPS5/KytyPS5/commit/dfec14aa8c59f8ea2bc4d87eba9854fc370161c6)
- **字体排版**：文字写入接口使用实际字形宽度推进位置，正确包含范围内的末尾字符，并修正渲染步骤与字符迭代终止。保留 1.0.1 的 Unicode、TTC 与 Noto 中文备用字形；此项修复文字显示和排版，不替换游戏翻译。[上游 eecd9821](https://github.com/KytyPS5/KytyPS5/commit/eecd982193ba5f3df3ddec500847ea3d99b87a0c)

DLSS 仍由一个默认开启的复选框控制，固定为 **1920×1080 → 2560×1440 DLSS 超分 + Vulkan FSR 3.1.4 2× 帧生成 + 车轮拖影修正**。相机、深度、运动矢量及无 HUD 画面的同帧检查继续启用。

## 验证范围

- 完成代码审查、Windows x64 发行构建及安装包文件完整性校验。
- 定时器回归已通过。存档重启测试发现并修正了测试程序对含空格路径的处理，修正后未重跑。
- 已补充存档挂载、字体混排和实际 Vulkan 深度清除／读回回归用例，但本批新增回归尚未完整执行。
- 本版未进行 GT7 游戏内验收，不宣称所有赛道补帧连续、帧率提升或全部视角问题已解决。深度修复属于底层兼容性改进；无法满足输入验证的场景仍会回退到原始帧。

## 使用与升级

退出旧程序后完整解压，运行 `launcher.exe` 或 `Start-GT7-Desktop.cmd`。覆盖升级时请保留原有 `_DownloadData`、`_SaveData`、`_Trophies` 及配置文件，并连同 `fonts` 和 `licenses` 文件夹一起复制。发行包不包含游戏文件或个人存档。

需要简体中文时，将游戏配置中的“主机语言”设为“简体中文”。随包包含 Noto Sans CJK SC 字体及其开放许可证。

本版未整体替换上游渲染器，也未改动着色器身份哈希；已有 DLSS／HUD 识别、FSR 呈现、中文字体回退和方向盘支持继续沿用。此前 1.0.1 的补帧修复及验证边界见[历史更新说明](RELEASE-1.0.1.zh-CN.md)。
